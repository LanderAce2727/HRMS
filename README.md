# DNSC Smart HRMS

Open the running system at **http://127.0.0.1:8085/index.html** and sign in with your existing account.

- Keep XAMPP MySQL running.
- To start the application again, run `Start-HRMS.ps1` or the PHP server command in [INTEGRATION_NOTES.md](INTEGRATION_NOTES.md).
- HR must publish real vacancies, configure employee pay rates, and set the faculty evaluation period.
- For a new installation using the supplied database, run `php scripts/install.php` after importing the original SQL dump.
